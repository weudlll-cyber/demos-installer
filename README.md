# Demos Node Installer

Installer and helper scripts to set up a Demos Network node on Ubuntu 24.04.
Includes: apt/dpkg lock handling, Bun + Docker install, systemd service, key backup.

Usage:
  curl -O https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/demos-installer/main/demos_node_setup.sh
  chmod +x demos_node_setup.sh
  ./demos_node_setup.sh
